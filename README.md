# ⚡ Daily Cashflow Command Center (5-in-1 Local Money Machine)

A zero-dependency Node.js web command center designed to generate fast daily cashflow from a single PC.

## 🚀 The 5 Built-In Engines

1. **🔍 Engine 1: Local Business Lead Hunter & Website Gap Auditor**
   - Queries OpenStreetMap (Nominatim + Overpass API) in real time for any city and high-ticket niche (`dentist`, `clinic`, `car_repair`, `plumber_trade`, `real_estate`, `lawyer`, `accountant`, `hotel`, `salon`, `gym`).
   - Performs a live HTTP + HTML technical audit on each prospect's website (checks HTTPS/SSL, mobile viewport tag, WhatsApp widget, online booking forms, load speed, and extracts emails).
   - Scores every lead `0–100` by immediate sales opportunity and exports an Excel-ready CSV lead pack.

2. **⚡ Engine 2: 1-Click Client Website & Pitch Studio**
   - Generates a customized, mobile-first conversion landing page for any prospect in `<1 second` inside `generated-sites/<slug>/index.html`.
   - Includes Click-to-Call, Click-to-WhatsApp, and online appointment capture.
   - Auto-generates tailored **WhatsApp outreach (with 1-click `wa.me` send link)**, **30-second phone script**, and **cold email pitch**.

3. **🎯 Engine 3: Real-Time Freelance Gig Sniper**
   - Monitors live `[Hiring]` and `[Task]` posts across Reddit (`r/forhire`, `r/slavelabour`, `r/DoneDirtCheap`, `r/freelance_forhire`).
   - Categorizes tasks by fulfillment speed and builds 1-click prompts to generate instant proof-of-work deliverables.

4. **🎬 Engine 4: RTX 4060 GPU + FFmpeg Video Repurposing Studio**
   - Hardware-accelerated (`h264_nvenc`) FFmpeg pipelines and local CUDA `faster-whisper` transcription commands to turn long-form videos into 9:16 vertical Shorts/Reels at `$0` API cost.

5. **📊 Engine 5: B2B Lead Pack & Digital Spreadsheet Factory**
   - Exports verified B2B CSV lead packs and spreadsheet templates for agencies, brokers, or digital storefronts.

## 🛠️ Quick Start

### Windows (1-Click)
Double-click `START_MACHINE.bat` to launch the server and open `http://localhost:3050`.

### Terminal
```bash
node server.js
```
Then open **`http://localhost:3050`** in your browser.
